# Use Broad Practice Pool as curated generation seeds

Broad Practice Pool will be a small curated set of broad practice seeds, not a fixed library of reusable dummy personas. When the Learner has no Active Ideal Customer Profile, Persona Generation selects or derives from a broad seed and generates a fresh LLM-created Customer Persona for the Session.

**Considered Options**

- Let broad practice be fully unbounded random persona generation.
- Store a fixed set of broad dummy personas.
- Use curated broad seeds to guide fresh LLM-generated Customer Personas.

**Consequences**

The product gets useful diversity and quality control without feeling canned. Broad seeds can cover different discovery situations, but hidden backstory, Customer Fit, Traps, Concrete History, and Opening Context are still generated fresh for each Session.
