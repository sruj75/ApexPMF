# Let Persona Generation create Opening Context

Opening Context will be generated by Persona Generation as a safe public projection of the Generated Session Case. Session Orchestrator delivers it at Session start, and UI renders it, but neither should invent the context independently.

**Considered Options**

- Let UI own generic Opening Context copy.
- Let Session Orchestrator construct Opening Context from selected fields.
- Let Persona Generation create Opening Context alongside the hidden persona truth.

**Consequences**

Opening Context can stay coherent with the Customer Persona while avoiding leaks of hidden backstory, Customer Fit, Traps, or Hidden Test Plan. Tests should verify that Opening Context is useful for starting naturally without exposing hidden mechanics.
