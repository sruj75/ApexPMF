# Pitwall as global shell module name

**Pitwall** is the sole product name for the global operational sidebar module (weekly focus, **Bottleneck**, what next). **Command**, **Dashboard**, and **Mission Control** are retired as names for that module. The default home route is `/projects/[projectSlug]/pitwall` (no `/command` route or redirect). **Practice Dashboard** remains the term for chrome inside the **Interview practice Node** only—distinct from **Pitwall**.
